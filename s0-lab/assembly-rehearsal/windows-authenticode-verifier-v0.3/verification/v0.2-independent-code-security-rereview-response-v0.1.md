## 2. Finding responses

### `BRM-AUTHV02-IR-002`

The canonical acquisition schema now requires the exact final volume-GUID
path and a versioned path-semantics identifier. The producer contract uses
`GetFinalPathNameByHandleW(FILE_NAME_NORMALIZED | VOLUME_NAME_GUID)`.

The grammar rejects ADS, non-volume-GUID form, slash ambiguity, nulls,
wildcards, empty or dot segments, and trailing-space/dot normalization. The
collector independently obtains the same final path from the supplied handle
and private lease. Record, supplied handle, and lease must be exact equal.

This defines the intended behavior for DOS and UNC inputs, hard-link aliases,
rename, case-only differences, reparse-derived names, and ADS: the caller path
is not authoritative, and any final name differing from the acquisition-
pinned volume-GUID path rejects.

### `BRM-AUTHV02-IR-001`

The adapter defines `CertFreeCertificateContext` and `CertFreeCTLContext` with
exact Boolean return signatures. Enumeration keeps the current returned
context in a local variable. On every exceptional processing exit, cleanup
frees that current context before store close.

The cleanup helper attempts certificate free, CTL free, and store close even
when an earlier cleanup result is false, then rejects. Fake-API tests verify
all three calls on successful and failed context-free paths. Normal
enumeration passes each context back to the next enumeration call, which
transfers and releases ownership without a second explicit free.

### `BRM-AUTHV02-IR-003`

Each chain call now records QPC frequency, start, and return counters in
addition to UTC FILETIME values. All are fixed 16-hex JSON text.

Duration and the freshness margin use the ceiling of monotonic QPC elapsed
time. The UTC and QPC intervals are cross-multiplied as integers and may differ
by at most two seconds. Reversal, overrun, and hidden discontinuity reject.

Tests cover UTC reversal, UTC overrun, QPC reversal, and a ten-second QPC
interval masked by a one-second UTC interval.
