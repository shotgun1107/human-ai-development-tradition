## 2. Finding response

### `BRM-AUTHV03-IR-001`

The chain builder establishes local ownership state before
`CertGetCertificateChain` and enters cleanup protection immediately after the
API returns. Return-time UTC and QPC sampling, chain parsing, serialization,
and all later work occur while a non-null returned context is locally owned.

The `finally` guard conditionally frees exactly once when the context is
non-null and ownership has not transferred. It therefore covers API failure
with a returned context, post-return QPC failure, and parsing failure without
double-free. A null context is not freed. On success, ownership transfers to
the caller, which performs the one normal cleanup.

Focused TEST evidence proves these fake-API paths and includes an AST assertion
that the return-time sampling and processing calls remain inside the ownership
guard. The direct isolated suite ran 23 tests: 21 passed, 2 skipped, with zero
failures or errors. That direct result predates the later `authority.py`
namespace correction; no tests have been rerun after that CODE change.

These results support a revision candidate only. They do not independently
close `BRM-AUTHV03-IR-001`.
