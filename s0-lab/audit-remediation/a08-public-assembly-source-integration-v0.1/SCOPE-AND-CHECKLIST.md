The bounded adversary consists of malformed public unit arguments, flags and paths; forged, copied, reused, or mutated diagnostic authority objects and records; controlled source substitutions; and stream API doubles with controlled errors, last-error changes, and close failures. Trusted prerequisites are the frozen source and TEST bytes, the measured Python executable, the ordinary host/tool behavior used to measure them, and the TEST evidence producer. Hostile interpreter/native dependencies, hostile same-process globals or introspection, arbitrary caller minting beyond the selected cases, and concurrent filesystem/process mutation are **unverified**. Their absence is not demonstrated; any claim requiring their resistance is blocked.

The bounded flow is: pinned inventories -> exact 27-source copy -> compile all 27 and import 25 safe modules -> public request/component/controller/storage/channel/stub unit calls -> pending-record publication through FakeBackend -> observer trace and witness -> diagnostic consumer predicates. Separate children exercise runtime guards and bootstrap refusal; stream doubles exercise the unchanged consumer-to-Win32 integration seam. TEST then measures 250 input hashes again and writes canonical results plus retained attempt copies. DOCUMENTATION authenticates released evidence and writes text, sidecars, and the 39-entry manifest. This sequence does not execute an authorized live assembly: live entry refuses, authority roots remain pinned to the original location, and the diagnostic implementation pin is never live authority.
