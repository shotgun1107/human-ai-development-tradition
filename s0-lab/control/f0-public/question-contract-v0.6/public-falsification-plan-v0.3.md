# URC-0.6 public falsification plan v0.3

- status: **public test-design proposal awaiting fresh independent public-only review**
- governed candidate: `URC-0.6-CANDIDATE`
- permitted future data: newly authored synthetic public material only, under later exact gates
- prohibited: sealed or hidden-oracle material and real, customer, personal, secret, or past-project material
- current gate: design only; no bank, labels, schema, implementation, simulation, session, measurement, or validation claim

## 1. Purpose and noncompensatory decision

This plan is designed to reject URC-0.6 before it can influence sealed work. It does not test representation superiority and does not validate S0, a central system, a tradition system, or Project Brain integration.

The design may advance only if every P0-P4 gate passes under artifacts, null calibrations, thresholds, algorithms, role boundaries, schedule, and ceilings frozen before confirmatory data. No gate compensates for another. A post-result change creates a new plan or contract version and requires an untouched bank.

## 2. Facts, inferences, and proposals

### 2.1 Authenticated predecessor facts

- v0.5 plan specified a four-stream P2 family, a paired P3 control, packet-cluster resampling, and resource ceilings.
- Independent review found its P2 prospective seed circular, its bootstrap confidence claims uncalibrated at null boundaries, its nested power procedure infeasible, its execution schedule open, its P3/P4 invalid-output rules inconsistent, and its role contracts incomplete.
- No public bank, implementation, simulation, executor output, measurement, or result exists.

### 2.2 CONTROL inferences

- Direct studentized packet statistics can be null-calibrated and power-tested without nesting a large bootstrap inside every simulated dataset.
- The scientific claim must be limited to the authorized dependence grids because grid calibration is not a distribution-free proof.
- Exact output-class consequences, immutable model revision evidence, balanced rotation, and access-control boundaries are preconditions rather than repairs.
- Prospective sample selection can depend only on immutable pre-bank artifacts. Bank-hash seeds belong only to post-bank confirmatory operations.

### 2.3 Proposals

All hypotheses, grids, calibration procedures, schedules, roles, thresholds, and ceilings below are proposals. They have not been implemented, benchmarked, calibrated, simulated, or reviewed independently.

## 7. P2 — no-record leakage and neutral-token equivalence

### 7.1 Topology and hypotheses

Two independently prompted observer identities O1 and O2 each run `original` and `neutral` variants. A stream receives the complete runner-visible prompt, codebook, question projection, and structural contract, but no records, record metadata, labels, row frequencies, other batches, outputs, or examples.

Each stream uses `K=N/12` fresh one-turn sessions. One session predicts the exact one-of-sixteen row for a frozen packet of 12 questions. Original and neutral variants use matched packets and separate sessions. Observers never see full-bank balance.

For stream `(o,v)`, `p[o,v]` is exact-row accuracy. For observer `o`, `delta[o]=p[o,original]-p[o,neutral]`.

The six blocking claims and allocation are:

- four leakage claims `H0-L: p>=0.15` against `p<0.15`, each at one-sided alpha `0.00625`;
- two equivalence claims `H0-E: delta<=-0.04 or delta>=+0.04` against strict interior equivalence, each at claim alpha `0.0125`.

Bonferroni allocation is `4*0.00625 + 2*0.0125 = 0.05`. This familywise statement is limited to the audited authorized null grid below.

### 7.2 Direct packet statistics

For a leakage stream, `x[k]` is the mean of its 12 correctness indicators in packet k. For an observer's equivalence test, `d[k]=x[original,k]-x[neutral,k]`. The standard error of a packet vector is its sample standard deviation divided by the square root of K.

With audited positive constants `cL(N)` and `cE(N)`:

- leakage passes only when `(mean(x)-0.15)/SE(x) < -cL(N)`;
- equivalence passes only when `(mean(d)+0.04)/SE(d) > cE(N)` and `(mean(d)-0.04)/SE(d) < -cE(N)`.

When a standard error is zero, leakage passes only if the constant packet mean is strictly below 0.15. Equivalence passes only if the constant packet difference is strictly inside `(-0.04,+0.04)`. No resampling occurs in confirmatory P2.

### 7.3 Joint latent simulation model

For observer o, variant v, question q, and packet k, simulation uses a probit latent value with:

- a question component shared by the two variants for the same observer/question;
- a session component shared by the twelve questions in one observer/variant packet;
- an independent residual;
- component variances `rho_q`, `rho_s`, and `1-rho_q-rho_s`;
- marginal correctness set by the inverse-normal threshold for the required probability.

O1 and O2 are independent. The dependence grid is `rho_q` in `{0.20,0.40,0.60}` crossed with `rho_s` in `{0.00,0.10,0.20}`, excluding sums at least one.

### 7.4 Boundary-null calibration before power

Calibration is performed separately for every candidate N and before any alternative-power run:

- leakage null grid: marginal `p=0.15` crossed with the dependence grid;
- equivalence null grid: `delta=-0.04` and `+0.04`, midpoint accuracy in `{0.10,0.15,0.20,0.30}`, crossed with the dependence grid; invalid marginal probabilities are excluded by the pre-bank manifest.

For each grid point, a fit stream of 100,000 directly simulated full datasets is generated. Candidate constants are restricted to `0.0000, 0.0001, ..., 8.0000`. Select the smallest constant whose fit false-pass fraction is no more than half the allocated claim alpha at every corresponding null grid point. If none exists, that N fails.

An independent audit stream of 100,000 datasets then uses the selected constant without adjustment. At every null grid point, the one-sided 99.9% Clopper-Pearson upper bound on false-pass probability must be no more than the allocated claim alpha. Audit failure rejects that N; the audit output cannot tune the constant. This is a finite-grid calibration claim, not universal finite-sample coverage.

### 7.5 Prospective power

After successful calibration, power is simulated jointly for all six P2 claims at true `delta=0`, marginal accuracy `p` in `{0.09,0.11}`, and every dependence-grid point. Each point uses at most 100,000 direct full-dataset simulations and the audited constants; there is no inner bootstrap.

Power is the proportion for which all six claims pass. The one-sided 99% Clopper-Pearson lower bound must be at least 0.80 at every point. A point may stop early only when its 99% upper bound is below 0.80, which fails N. Passing classification always uses the full precommitted 100,000 simulations.

## 9. P3 — representation-alignment equivalence

### 9.1 Sixteen-code control and topology

The control has one decision field `outcome_code` accepting the equal-length opaque strings `K01` through `K16`. A post-bank Fisher-Yates permutation maps codes one-to-one to the sixteen rows using the frozen control-map seed. Its codebook states all row meanings in code order and contains no examples, frequencies, recommendations, or condition language.

The control and URC envelopes are otherwise identical in semantics, citations, affected IDs, uncertainty, reason obligation, canonicalization, model, authority, tools, opportunities, and limits. The control is a measurement artifact, not a successor candidate.

Each grammar is crossed with public A-D representations. Questions are grouped into `K=N/8` matched packets. Each packet has eight fresh sessions, one per grammar-representation cell, and each session answers its assigned eight questions once.

### 9.2 Estimator and direct test

Let exact structured-decision correctness be `Y[q,g,r]`. A parseable schema-invalid or schema-valid semantically wrong answer has Y=0; a schema-valid correct decision has Y=1. Technical absence, transport invalidity, or unparsable JSON invalidates the suite and is never imputed.

For each grammar, its representation gap is the all-question mean of `(Y[C]+Y[D]-Y[A]-Y[B])/2`. `theta` is the URC gap minus the control gap. The packet contrast `z[k]` applies this formula within one matched eight-question packet, and `SE(z)` is the sample standard deviation across packets divided by the square root of K.

With audited `c3(N)`, P3 passes only when both `(mean(z)+0.10)/SE(z) > c3(N)` and `(mean(z)-0.10)/SE(z) < -c3(N)`. With zero standard error, the constant contrast must be strictly inside `(-0.10,+0.10)`. No resampling occurs in confirmatory P3.

### 9.3 P3 boundary calibration and power

The joint probit simulation shares a question component over all eight cells, a session component within each grammar-representation packet session, and independent residuals. The dependence grid is `rho_q` in `{0.10,0.30,0.50}` crossed with `rho_s` in `{0.00,0.10,0.20}`, excluding sums at least one.

Base cell grids use A/B marginal `p_low` in `{0.55,0.65,0.75}` and common C/D gap in `{0.00,0.10,0.20}`, excluding probabilities outside `[0.05,0.95]`.

- Null calibration sets the control cells to the base values and shifts both URC C/D marginals by `theta=-0.10` or `+0.10`. It uses the same 100,000-fit, fixed 0.0001 constant grid, independent 100,000-audit, half-alpha fit rule, and 99.9% Clopper-Pearson audit rule as P2, with claim alpha 0.05 for the two-sided 90% equivalence test.
- Power sets identical cell marginals for both grammars, so `theta=0`, and uses every base/dependence grid point. Each point uses at most 100,000 direct datasets and the audited constant. Its one-sided 99% power lower bound must be at least 0.80.

There is no nested bootstrap. Calibration is applied before power and sample selection. The error-control claim is explicitly limited to the audited P3 null grid.

## 10. Deterministic sample selection and balanced schedule

### 10.1 Smallest-sufficient N

Evaluate candidate N values in ascending order. An N qualifies only if every P2 and P3 null audit passes and every P2 joint-power and P3 power lower bound is at least 0.80. Select the first qualifying N and stop. If no N through 720 qualifies, public authoring does not start. Margins, grids, alphas, statistic formulas, constants, or power thresholds may change only in a newly reviewed plan version.

### 10.2 Schedule construction

The signed schedule is constructed after bank freeze and before any model call.

- P2 base cells are `O1-original`, `O1-neutral`, `O2-original`, `O2-neutral`. Packet k rotates the base order left by `k mod 4`; positions 1-2 and 3-4 are two sequential waves of size two. Every authorized K is divisible by four, so each cell occupies every serial position equally.
- P3 base cells are `URC-A`, `CONTROL-C`, `URC-B`, `CONTROL-D`, `URC-C`, `CONTROL-A`, `URC-D`, `CONTROL-B`. A bank-hash-seeded permutation of rotations 0-7 repeats; packet k uses its assigned rotation. Positions 1-3, 4-6, and 7-8 form waves of sizes three, three, and two. Across the schedule, each cell's count in every serial position and wave differs from another cell's by at most one.
- A wave must finish before the next wave begins. Concurrent sessions never exceed three. Packet order is a bank-hash-seeded permutation fixed in the schedule manifest.

The schedule checker must prove these counts before execution. A mismatch invalidates the schedule before calls begin.

### 10.3 Revision, load, and drift evidence

The test does not start unless the provider exposes an immutable exact model revision or fingerprint shared by every cell. The manifest also freezes reasoning level, service tier, region, tool/network state, token limits, and timeout.

For every session, CONTROL records scheduled wave, queue time, provider start, first-token time when available, finish time, revision/fingerprint, tier, region, throttling and error indicators, and raw output hash before reading semantics.

Any revision, reasoning, tier, region, authority, or tool-state difference; provider retry; rate-limit retry; undeclared routing change; session overlap across waves; or execution window longer than seven calendar days invalidates the suite before semantic outputs are opened. Latency variation without one of those events is retained for P4 and never justifies selective rerun.

## 12. P4 — comparator reliability and executor burden

### 12.1 Exact output consequences across P3 and P4

| First-output class | P3 decision correctness | P4 schema success | Gate consequence |
|---|---:|---:|---|
| technical absence | not defined | diagnostic 0 only | whole suite invalid; P4 cannot pass independently |
| transport invalid | not defined | diagnostic 0 only | whole suite invalid; no M5 |
| JSON unparsable | not defined | diagnostic 0 only | whole suite invalid; no M5 |

This table replaces v0.5's ambiguous “missing or invalid cell” language. A parseable schema-invalid cell does not invalidate P3 and therefore P4's less-than-100% schema threshold is coherent. Classes 1-3 do invalidate the noncompensatory suite.

### 12.2 Comparator reliability

Two independently implemented comparators run the complete frozen mutation set 100 times each. Pass requires byte-identical mechanical atoms, availability, source sets, consumed sets, events, diagnostics, and totals over all 200 runs. The two semantic judges must also agree exactly on every semantic-reason mutation and confirmatory `short_reason`; disagreement fails P1/P4 rather than being resolved by CONTROL.

### 12.3 Burden thresholds

Using first P3 outputs, every condition must hold:

- at least 95% of URC responses are schema-conforming;
- URC schema success is no more than three percentage points below control;
- maximum minus minimum URC schema success across A-D is at most five points;
- URC pooled median elapsed time is no more than 20% above control;
- URC pooled median raw output bytes are no more than 20% above control;
- every valid canonical response is at most 7,680 bytes and every raw response is at most 8,192 bytes;
- no answer exceeds four cited or four affected IDs.

The matched P3 packet is the resampling unit. For these five threshold statistics only, use 100,000 packet-cluster percentile-bootstrap replicates with `PCG64-DXSM` and a post-bank seed containing the frozen bank hash and metric ID. Quantiles use one-based rank `ceil(q*100000)`, clamped to the replicate range. Two-sided 95% intervals must place the complete interval on the passing side of each threshold. This single post-bank resampling analysis is not nested inside prospective simulations.

P4 cannot rescue P0-P3.
