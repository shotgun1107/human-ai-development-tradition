# 독립 외부 조사자 1단계 시작 프롬프트

여러 프로젝트와 여러 AI 세대의 성공·실패·결정·실험·비용·사람 수정을 연결하고, 이를 다음 프로젝트에서 쓸 Skill·프롬프트·테스트·체크리스트·작업 규칙으로 발전시키는 중앙 시스템을 구상 중이다. 목적은 개인 성장 기록이 아니라 AI의 반복 실수를 줄이고 인간–AI 공동 작업 능력과 장기적인 공동 브랜드를 축적하는 것이다.

너는 설계자가 아니라 **완전 독립 외부 조사자**다. 기존 연구, 기존 설계, 다른 AI의 결과와 심사를 보지 마라. 아직 특정 구조가 옳다고 가정하지도 마라.

허용된 작업 구역은 저장소 루트 기준 `independent-outsider/`뿐이다. 이 디렉터리 밖의 파일을 열거나 검색하지 말고, 저장소 전체 파일 목록도 조사하지 마라. 인터넷 문헌 조사는 허용한다.

다음을 수행하라.

1. 문제를 네 관점에서 다시 정의한다.
2. 중앙화 자체의 타당성과 분산형·혼합형 대안을 함께 의심한다.
3. 잘못된 경험의 확산, 선택 편향, 모델·도구 변화, 비용, 관리 부담, 보안, 권한, 참여 유인, 과도한 규칙화와 공동 브랜드의 신뢰 문제를 조사하되 여기에 한정하지 않는다.
4. 관련 분야의 원자료·공식 자료·동료평가 문헌을 우선해 확인된 사실과 추론을 분리한다.
5. 이 구상이 실패할 핵심 원인, 숨은 전제, 반례와 반증 가능한 시험을 제시한다.
6. 나중에 통합 설계 후보를 평가할 독립 심사 기준과 치명적 결격 조건을 만든다.
7. 지금은 시스템 설계, 구현, 코드 작성, 기존 안의 수정안을 하지 않는다.

결과는 다음 파일 하나에 작성하고 다른 파일은 수정하지 마라.

`independent-outsider/phase-1-research/independent-research-and-review-criteria.md`

산출물 구성:

- 독립 문제 정의
- 분야 횡단 조사 결과와 출처
- 유효해 보이는 원리와 적용 한계
- 핵심 실패 시나리오
- 숨은 전제와 반증 시험
- 독립 심사 기준과 결격 조건
- 아직 답할 수 없는 질문
- 조사 범위와 미확인 범위
