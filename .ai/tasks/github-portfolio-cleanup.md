갱신일: 2026-10-02 (Asia/Seoul). 일반 Git·문서 유지보수 기록이며 연구 역할의 입력으로 자동 허용되지 않는다.

## 목표와 완료 조건

- 기존 저장소 URL과 비공개 설정을 유지하면서 제출용 소개, 현재 문서, 브랜치와 커밋 제목을 정리한다.

- 원래 refs와 커밋을 복구할 수 있게 보존한 뒤 제목만 한국어 규약으로 정돈한다. 작성자·개발 날짜·부모 관계·과거 결과를 꾸미거나 소급 수정하지 않는다.
- 원격 반영 후 main·보관 refs·정리한 브랜치·GitHub 안내와 로컬 범위 밖 상태를 확인한다.

## 승인 범위와 금지 범위

- 사용자는 제출용 GitHub의 문서·브랜치·과거 커밋 제목 정리, 원본 백업, 원격 반영을 요청했다.
- 미분류 항목 4개를 이름·내용 접근이나 변경 없이 그대로 둔 채 이번 작업에 필요한 백업·fetch·정리 브랜치·커밋·원격 main 이력 갱신·확인된 브랜치 삭제를 수행하는 1회 예외를 별도 질문으로 확인받았다.
- 역할은 root/CONTROL의 일반 유지보수다. 대상 저장소는 `shotgun1107/human-ai-development-tradition` 하나이며 기존 작업 폴더의 범위 밖 4개 항목은 입력·출력 대상이 아니다.
- 출력은 이 작업 기록, 현재 안내 문서, 저장소 설명, 필요한 Git 객체·refs와 저장소 `.git/portfolio-cleanup-20261002/` 아래 복구 자료에 한정한다. 일반 실행 도구나 새 검증 프레임워크를 만들지 않는다.
- F0 내용 접근, 숨은 oracle·S0/E0·모델 호출, 공개 여부 변경, 다른 저장소 변경, 시스템 설치, 기존 근거 바이트 수정은 승인하지 않았다. Git 보존·재전송은 AI 내용 접근을 허용하지 않는다.
- 동결 입력의 원래 SHA-256과 과거 검증 주장은 그대로 둔다. 새 커밋 ID를 과거 기대값에 덮어쓰지 않는다. 작업 기록·백업을 연구 실행자나 독립 검토자에게 자동 전달하지 않는다.
- 예외는 이번 정리와 사후 확인으로 끝난다. 원격 refs가 동결 값과 달라지거나 보호 집계·내용 보존 검사가 실패하면 해당 게시·삭제를 중단한다. 이후 Git 작업에는 정상 분류·승인 절차를 다시 적용한다.
