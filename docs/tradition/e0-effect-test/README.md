# E0 전통 효과시험 설계 패키지

- 상태: `제안 v0.1 — 독립 심사 전, 설계 전용`
- 기준선: `central-system-v2.1-s0-preparation`
- 제안 라벨: `E0`는 아직 동결된 공식 단계가 아니다.
- 허용 범위: 효과시험의 인과 질문, 측정, 비용, 게이트, 독립 심사 방법 설계
- 현재 금지: 시험 자료·정답·숨은 oracle 작성, 구현, 모델 실행, 채점, 효과 판정

## 목적

이 패키지는 문서화되고 정제된 AI 개발 전통을 새 세션의 AI에 문서 주입 또는 결정적 검색으로 제공했을 때, 전통을 제공하지 않은 같은 조건보다 겉모양이 달라진 후속 과제의 판단이 좋아지는지를 가장 작고 반증 가능하게 시험하는 방법을 제안한다. 사용자의 1차 목적은 개인 성장 일지가 아니라 세션과 모델 교체 뒤에도 이어질 수 있는 AI 측 작업 역량이다.

설계는 다음 네 층을 분리한다.

1. **기계적 정합성:** 해시, 조건 배정, 가시성, 자원 한도, 출력 보존이 계획대로였는가.
2. **인과 효과:** 정제된 전통 제공이 중대 판단 오류를 줄였는가.
3. **부작용:** 과잉 적용, 오래되거나 철회된 교리 사용, 무관 검색, 거짓 확신이 늘지 않았는가.
4. **운영 비용:** 입력·출력 토큰, 모델 호출, 대기시간, 사람 능동시간, 현금 비용이 승인 상한 안인가.

## 제안된 최소 경로

첫 저비용 파일럿은 같은 합성 후속 과제를 독립된 새 세션에서 `전통 없음`과 `정제된 전통` 두 조건에 각각 한 번 제시한다. 이는 전달 패키지 전체의 효과가 존재할 가능성과 위해 신호를 선별할 뿐, 관련 내용의 효과를 추가 토큰이나 일반적 조언과 완전히 분리하지 못한다. 내용 특이적 효과를 주장하려면 길이·형식 일치 무관 대조를 추가한 확인시험이 필요하다. 원본 기록 조건은 “정제가 원본 접근보다 낫다”는 별도 질문을 물을 때만 추가한다.

## 명시적 비주장

이 패키지와 향후 제한적 통과는 다음을 구현하거나 입증하지 않는다.

- S0의 통과 또는 특정 표현 후보의 우승
- E0의 공식 단계 확정, 시험 자료·oracle·runner의 완성, E0 실행 또는 통과
- 중앙 전통 시스템이나 Project Brain 통합의 유효성
- 실제 고객·공모전·운영 프로젝트의 품질, 안전성 또는 경제성
- 모델 가중치 학습, 파인튜닝 또는 동일한 AI 인격의 지속
- 서로 다른 모델 사이의 전승 효과
- 모든 과제군에 적용되는 범용 교리의 유효성

초기 개입은 모델 밖의 검색 가능한 문서를 문맥에 넣는 방식이다. 관찰 가능한 것은 특정 모델·판본·프롬프트·자원 봉투 아래에서의 출력 차이이며, 이를 “모델이 학습했다”라고 부르지 않는다.
